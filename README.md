## 四、個人回答

### 問題一

因為桌遊名單裡的 Amy 重複報名了兩次，所以雖然 list 裡有 4 筆資料，實際上只有 3 個人，費用應該用 3 人計算。

list 會保留原本的順序和重複姓名，set 則會把重複的姓名去掉，但不保留原本的排列順序，所以最後要用 sorted() 排序。

### 問題二

因為測試三的兩場活動都是 Amy、Ben、Cora，所以兩個集合的交集和聯集都是這 3 個人，兩個差集都是空集合。

雖然只有 3 位不同的人，但每個人都參加兩場活動，所以報名人次是 3＋3＝6 人次。

桌遊費用是 3×120＝360 元，電影費用是 3×80＝240 元，總共是 600 元。
